Usage:
  telnet [--dumb] HOST [PORT]
Use a monochrome VT100/ANSI terminal over unencrypted TCP. Default
port: 23. Both streams must be terminals.
Options:
  --dumb        Use the line-oriented NVT instead of a full-screen
                terminal.
Ctrl+] then q exits; Ctrl+] twice sends Ctrl+]. Command-period
cancels locally. Ctrl+C sends Telnet IP.
Return sends CR LF; Backspace sends DEL. Application arrows are
supported.
Uses libtelnet and TERM=vt100 with NAWS. Resize before connecting;
size is fixed for the session.
Supports inverse, cursor movement, erase, scroll regions,
insert/delete and ASCII line graphics.
No colour, UTF-8, double-size rows, alternate-screen history,
bold, underline, blink or VT52.
No TLS, autologin, transfers or urgent SYNCH. DNS/TCP may delay
cancellation.
No idle timeout. Incomplete controls time out after 30 seconds.
Overflow ends the session.

cancelled.
