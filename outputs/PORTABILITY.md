# Unix portability capability matrix

10 November 2026. **Tested** means the stated subset has existing evidence;
**partial** means implemented with gaps; **experimental** means unpublished and
not fully validated; **absent** means no implementation found in this checkout.
No category implies POSIX conformance. Source paths are authoritative.

| Capability | Current support / evidence | Important gap and consumers |
| --- | --- | --- |
| File I/O / descriptors | Tested data-fork read/write/close, shell descriptors 0–2 and redirection; port descriptors 3–11, partial `fstat` and `lseek` (`src/streams.inc`, `src/port-files.inc`, `src/ports/runtime.c`). | No general descriptor objects, dup/pipe/socket readiness. All applications need reusable ownership/errors; awk child pipes, Telnet and SSH need more endpoint types. |
| C stdio / seeking | Twelve owned streams, 512-byte buffers, cleanup/exit interception, 16 KiB getline limit; selected grep/sed/pipeline tests. Experimental `fdopen`, exclusive opens and update-mode native opens. | `funopen` receives no seek callback: raw `lseek` is not `fseek`/`ftell`. `port_fopen` does not fully implement update-mode read/write selection; `fileno` supports stdio and fdopen-owned streams but not every file stream. Nano/vi/SFTP need exact tested semantics. |
| Metadata / native operations | Tested catalog flags, dates and both forks in native tools; copy stages replacements. `/mnt`, bounded symlinks and HFS paths work. | Portable `stat/access/realpath` are nano-specific experimental adapters. `access` does not establish volume writeability; access/ctime fields approximate mtime and ownership fields are synthetic zeroes. Do not export these as full POSIX truth. Test read-only media, changing files and resource-fork preservation during editing. |
| Directories | Native utility traversal/catalog iteration tested (`src/commands/inspect.c`, `files.c`). | `src/ports/terminal/dirent.h` declares DIR/opendir/readdir/closedir but supplies no implementation. Header presence is not directory API support. Needed for portable editors, completion and SFTP; do not confuse native CLI `ls` with libc readdir. |
| Invocation / processes | Tested synchronous fresh CLX1 image and exit status 0–255; 126 invalid image, 127 lookup failure; cooperative cancellation (`src/module.inc`). | Shared host address space, stack, stdio/newlib and shell globals. No worker application launch, fork/exec/wait, process isolation or child API. Awk `system/popen/pclose` explicitly fail. Needed before nested awk and ordinary SFTP's spawned SSH transport. |
| Arguments / environment / cwd | PATH and bounded shell env/cwd; awk snapshot; experimental terminal private 24-entry environment, ≤1024 bytes per name/value pair. | Shell environment still only 16 entries with 127-byte values; wrappers differ and host cwd/streams are global. Nano `putenv` adapter copies values instead of POSIX pointer-sharing; no generic per-child cwd/attribute inheritance. All ports need an agreed context. |
| Memory / cleanup | Demand allocations under fixed 96 KiB cap; tracked free, stream/descriptor/temp cleanup; image/metadata separate, metadata freed before entry. Selected fault/repeated-run tests. | Not adaptive admission or guaranteed recovery reserve. Host allocations, FILE pool, screen and stack are outside this cap. Single 768 KiB partition/64 KiB stack; nesting and worker budgets unimplemented. All ports, especially nano/vi/SSH, need measured per-command budgets. |
| Pipes / streams | Finite sequential HFS temporary-file spools, redirection ordering, EOF/status and Ctrl+C tests (`src/sh.inc`). sort spills to disk. | No concurrent producer/consumer execution, bounded live pipe, broken-pipe semantics or pollable stream set. Required by awk command pipes, long-lived pipelines and SFTP/SSH composition. |
| Terminal / ncurses | Shell rendering/history tested. Real upstream ncurses 6.5 demo guest-tested; native dirty-row copy, 40×132 bounded grid, 128-byte keys, embedded truthful `clarice` terminfo (`src/editor-screen.inc`, `src/ports/terminal/`). | Experimental raw/canonical read, ISIG, partial select/ioctl and timeout support. VMIN>1/inter-byte timing, full output flags/flow control/drain semantics are not implemented despite accepted termios fields. Resize disabled during ownership. End-to-end nano not verified; vi/Telnet/SSH need agreed capabilities/resize. |
| Signals / cancellation | Ordinary commands yield/longjmp to status 130; demo raw Ctrl+C and registered SIGINT handler observed. Local signal/raise/sigaction code and masks present. | No OS asynchronous delivery, process signalling or jobs. Later mask/sigaction edits exceed earlier guest evidence. Some accepted flags/modes only store state; audit rather than claim false success. Terminal gettimeofday uses uptime ticks, not Unix wall time. |
| Shell | mrsh parsing plus native execution adapter; 30 selected fixture matches reported; quotes/variables/loops/functions/substitution/redirection and finite pipes. | Bounded scripts (8 KiB), substitution (2047 bytes), arguments and nesting; no complete shell options, traps, job control, faithful subshell/process semantics. Future awk `system()` must execute shell syntax, not split a command string on spaces. |
| Runtime / maths | Pinned Retro68/newlib C ABI, direct function and data imports; software floating-point helpers/libm for awk, GNU regex/getopt helpers in nano probe. | Not a stable portable libc ABI. Exposes FILE internals, `_ctype_`, shell data and private Mac types; errno/locale/reentrancy/stack need isolation review. Baseline uses software arithmetic, not assumed FPU. Locale support remains C/byte-oriented; no general Unicode terminal promise. |
| Networking | Experimental native serial command only (`src/commands/serial.c`); optional HOSTNAME string is not DNS. | No socket/TCP/DNS/Telnet/SSH/SFTP implementation or validated serial session. Require native installed-stack adapter, readiness/timeouts, connection errors and secure entropy/crypto for SSH. |
| Packaging / updating | Legacy CLX1 plus format-2 runtime-major/minor and capability requirements; startup preserves all existing entries. Explicit validated staging/replacement, retained old files and recovery. [Task 2 host/CPU/Plus evidence](task2/TEST-REPORT.md). | Requested Plus normal-workflow checks pass; guest power-loss/durability faults remain untested. No version ordering, automatic update discovery, signature verification, concurrent-writer support or public SDK. Native ABI still tied to pinned toolchain/private types. Nano build still relies on prepared ignored work files. |

## Application dependency gates

| Application | Essential shared services still to complete/validate | Optional features that can be explicitly excluded initially |
| --- | --- | --- |
| ncurses | Accurate terminal mode/readiness contract, dimensions, input/refresh, owned allocation and restoration; tested screen transport in both backends. | Wide characters, colour, mouse, disk terminfo database and dynamic resizing until implemented; never advertise absent capabilities. |
| nano | Existing real ncurses/GNU helpers; safe stdio/fdopen/seek, metadata/path errors, bounded adaptive memory, cleanup and startup timing. | Upstream tiny build, NLS/UTF-8 disabled as documented; no synthetic user database. Tiny mode is not modern full nano parity. |
| One True Awk | Nested shell execution, child completion/status, live command-pipe endpoints, context/stack isolation and deadlock-free close. | Platform-specific Unix processes/jobs may remain absent, but `system()` and command pipes cannot remain stubbed at the completion milestone. |
| vi | Select faithful upstream first; terminal, editing/save/recovery and path services. Determine whether selected implementation needs curses/termcap. | Large optional features only through documented upstream configurations; dependency list not settled before source choice. |
| Telnet | TCP/DNS, bidirectional nonblocking readiness, terminal modes/size, protocol negotiation and cancellation. | Server, local process jobs and unrelated serial hardware control. |
| OpenSSH client | Maintained upstream source/compatibility layer, robust networking/time/entropy/crypto, key/config/known_hosts I/O, terminal and bounded scheduling; replace client-local identity lookups with explicit profile data where needed. | Initial agent/forwarding/multiplexing/proxy/helper features may be excluded explicitly; never bypass host-key verification or fake ownership protection. |
| SFTP | SSH transport, file/dir/metadata/seek, bounded transfers and child/stream lifecycle; define HFS attribute differences. | Unix ownership changes cannot report success; server and background daemon facilities are not needed for client transfers. |

Essential shared work is descriptors, invocation state, allocation/cleanup, portable
native files and terminal/stream transport. A Unix kernel, simulated accounts,
root/chmod, fork address-space cloning, local ptys or a second TCP stack are not
prerequisites merely for branding. Some upstream client features may require
subprocesses or IPC; disable or port those paths deliberately. See [feasibility](FEASIBILITY.md).
