# Batch 3D native removal regression

`python3 tests/filesystem-native-remove/host.py` compiles the production removal
and namespace conversion functions with a disposable in-memory native catalog.
The accepted1968 negative control deletes the wrong sibling; the candidate must
remove the literal slash-named file only. Sanitizers, native errors, allocation
failure, cancellation, retry and byte-identical unaffected nodes are checked.

Run `guest.py` with macOS `/usr/bin/python3` against the owned Snow forward23260.
Use a stopped clone of the Batch3C fixture, normal candidate Core/tools, existing
fsprobe and Batch3B resource-bearing source. It uses only /tmp/batch3d and Perf
scratch paths. `performance.py` compares three alternating pairs of1968/1969 rm
on the existing100-file Perf fixture; install images as before/rm and after/rm,
with the candidate cp as after/cp. Do not point these tests at user data or hardware.
